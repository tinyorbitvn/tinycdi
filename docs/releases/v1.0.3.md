# TinyCDI 1.0.3

TinyCDI 1.0.3 is a web-portal bug-fix release. It fixes two admin forms
that could lose an edit, and polishes error dialogs, tables and tabs. The
API, backend, operator, runtime images and chart templates are the same as
in [1.0.2](v1.0.2.md).

## Changes

### Admin forms

- **Session policy and tenant limits keep your edit.** If the page
  reloaded the policy or quota just as you changed a field, the reload
  could undo the change and leave the save button disabled. The form now
  takes the reloaded values before you can edit them.
- **The tenant limits dialog keeps its conflict warning.** When someone
  else changed the limits first, the dialog loads their values and now
  keeps the "review and retry" warning on screen, so it is clear why the
  values changed.

### Portal

- **Purge and attach errors.** The purge and attach dialogs now lead with
  the guidance for the error code, like the other error messages, with
  the server message underneath.
- **Workspace list on phones.** The workspace card shows the template.
- **Tables.** Row hover no longer tints empty or loading rows, and a
  stacked row on a phone tints as one block. Stacked tables keep their
  table semantics for screen readers.
- **Tabs.** On narrow screens the tab row fades only at an edge that hides
  more tabs, so the focus ring of the first and last tab is fully visible.
- **Default user limit.** The admin stat shows a dash while it loads.

## Upgrade from 1.0.2

1.0.3 has no database migration, no CRD change and no new chart value.
Upgrade in place:

```bash
helm upgrade tinycdi oci://ghcr.io/tinyorbitvn/charts/tinycdi --version 1.0.3 \
  -n tinycdi-system -f my-values.yaml
```

Verify the images with the `cosign verify` command in
[provenance.md](../security/provenance.md#verification-side-what-a-consumer-runs)
before you deploy.
