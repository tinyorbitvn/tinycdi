# TinyCDI 1.0.1

TinyCDI 1.0.1 is a web-portal release. It changes the look and layout of
the portal and admin console and refreshes the README. The API, backend,
operator, runtime images and chart templates are the same as in
[1.0.0](v1.0.0.md).

## Changes

### Portal and admin console

The portal and admin console now follow the Orbit design system more
closely, in light and dark mode and on narrow screens. Routes, flows and
API calls are unchanged.

- **Shared components.** Buttons, field labels, hints, table headers and
  status badges use Orbit's sizes. Badges no longer stretch inside table
  cells. Cards have no shadow. Dialogs have a darker backdrop, a border in
  dark mode, and their body text no longer repeats the title.
- **Dark mode.** The page canvas is flat, danger buttons and capacity
  meters use full-strength status colours, and table headers have the same
  contrast as in light mode.
- **Mobile.** Workspace, event and condition tables stack each row into a
  block below 768 px. The tab bar scrolls horizontally and keeps the
  active tab in view.
- **Workspace list.** The phase shows as a badge with the progress
  sentence underneath. Failed and stopped rows show no elapsed timer, and
  a failed row reads "Failed at step N of M".
- **Errors.** The error banner's title is the guidance text for the error
  code instead of the raw code. The server message, code and request id
  follow underneath.
- **Detail pages.** Workspace, retained data and session pages have a back
  link. A retained data item is titled by its workspace name, and its full
  id has a copy button.
- **Admin overview.** Counts are shown as stat cards and capacity meters
  sit in an even grid.
- **Admin forms.** Session policy and audit filters use a two-column form
  on wide screens. The audit date fields say they use local time. Identity
  facts on a user's page are under their own heading.
- **Signed out.** The page shows the product logo on a solid card.

All new text is translated into English and Vietnamese.

### README

The README describes the 1.0 feature set and shows screenshots of the
portal, admin console and both runtimes. Portal and admin screenshots
follow the reader's light or dark GitHub theme.

## Upgrade from 1.0.0

1.0.1 has no database migration, no CRD change and no new chart value.
Upgrade in place:

```bash
helm upgrade tinycdi oci://ghcr.io/tinyorbitvn/charts/tinycdi --version 1.0.1 \
  -n tinycdi-system -f my-values.yaml
```

Verify the images with the `cosign verify` command in
[provenance.md](../security/provenance.md#verification-side-what-a-consumer-runs)
before you deploy.

## Known issues

- **Reopening a closed session tab asks to take over**
  ([tracked on GitHub](https://github.com/tinyorbitvn/tinycdi/issues/208)).
  After you close a session tab and open the workspace again, the portal
  can say that another session is connected, because the gateway still
  holds the lease of the closed tab. Choose "Take over session" to
  connect. A fix is planned for a later release.
- The [1.0.0 known limitations](v1.0.0.md#known-limitations) still apply.
