# TinyCDI v0.3.1 — release notes

v0.3.1 is a patch release on v0.3.0: rollout-safety and correctness
fixes. No database schema, public API or CRD changes.

## What is new

- Frontend pre-stop drain: on SIGTERM a terminating frontend pod fails
  `/healthz` at once and keeps serving for `frontend.drainDelay` (8 s
  default) while the endpoint removal reaches kube-proxy and the edge —
  a frontend rollover no longer routes requests to a dead pod.

## Upgrading from v0.3.0 (or older)

The procedure is `docs/runbooks/upgrade.md`.

- Upgrading FROM v0.3.0 (or older): expect a few seconds of portal 5xx
  while the old frontend pods terminate — they predate the drain, so the
  edge can briefly route a sub-request to a pod that is already exiting.
  From v0.3.1 on the frontend drains (`frontend.drainDelay`).
